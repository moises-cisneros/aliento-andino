# Panel Web de Gestión para Docentes

El panel web está diseñado para profesores de academias, colegios y talleres de música andina.

## Funcionalidades Principales

### 1. Gestión de Aulas y Grupos

- Crea grupos de clase (por ejemplo: "Taller de Zampoña - Nivel Inicial").
- Genera códigos de invitación para que tus alumnos se unan desde la app móvil con un toque.

### 2. Asignación de Tareas y Repertorio

- Selecciona lecciones existentes o sube canciones personalizadas en formato MusicXML / MIDI.
- Define fechas límite y umbrales mínimos de afinación para aprobar la práctica.

### 3. Seguimiento y Analítica de Alumnos

- Consulta métricas consolidadas de tiempo de práctica semanal y avance curricular.
- Observa qué notas presentan mayores desviaciones de afinación o problemas posturales en tu grupo.
