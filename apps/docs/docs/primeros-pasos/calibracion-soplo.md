# Calibración de Soplo ("Soplo Suave")

El asistente de calibración inicial mide la dinámica de soplo del estudiante antes de iniciar las lecciones para ajustar el umbral de detección de energía acústica:

1. El alumno sopla de forma continua y suave durante 3 segundos.
2. La aplicación mide el ruido de tu entorno y la intensidad de tu soplo.
3. Se ajusta la sensibilidad del afinador para que reconozca tus notas con precisión.
